Proliferate · iOS 26 · Liquid Glass

Proliferate for iPhone — steer cloud agents from anywhere.

High-fidelity mockups for the cloud-only native app (Expo / React Native, targeting proliferate.theitdept.au). Glass is reserved for the control layer — bars, docks, capsules, sheet chrome — while transcripts, terminals, and diffs stay on opaque ink surfaces. Everything git-addressable is set in SF Mono. Companion documents: design-system.md and information-architecture.md.

Material

The glass ladder

One GlassSurface component resolves per device and per accessibility setting. Same slot, four renders — the app must be fully legible at every tier.
